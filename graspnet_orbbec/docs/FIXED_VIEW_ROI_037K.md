# 当前固定视角ROI（037K）

2026-11-04，根据用户确认的固定摆位配置，参考原始快照 `output/wire_grasp/real_20261104_213032_531671352/capture/rgb.png`，尺寸640×480。窗口截图包含标题、双栏和缩放，不能直接用窗口坐标作为RGB坐标。

`configs/default.yaml` 默认：

```yaml
wire:
  auto:
    roi_xyxy: [40, 160, 555, 218]
    roi_reference_size_wh: [640, 480]
```

范围为原图x∈[40,555)、y∈[160,218)，包含当前右端端子和足够长的线身，避开桌孔、下方夹爪、左侧大固定块及大部分右侧支架。端子附近的固定块仍有少量进入ROI，不能因此认定所有干扰已消失。

- 按[主手册](REAL_GRASP_STARTUP.md)原有命令启动即可使用默认ROI。配置在启动时加载；当前窗口需Q退出并重开，按R仅重跑旧配置下的同一冻结图片。
- 识别完成后，两栏显示蓝色ROI边框，标题标明“ROI已限制”；左侧原图仍完整显示，不代表在做全图推理。
- 自定义 `--config` 使用其自身设置；命令中的显式 `--roi`优先于默认。需要临时指定时，将 `--roi 40 160 555 218`添加到原preview/recognize命令。
- 可在配置中设 `roi_xyxy: null`恢复全图；换视角或移动摆位须重新确定ROI。尺寸不符合640×480时直接拒绝，不自动缩放；尺寸相同也不保证视角相同，需要操作者核实。
- 左侧线身穿过ROI边界属于截断，不能把该边界当作物理线头。目标交界和至少14mm实际线身须完整位于区域内。
- ROI只改变推理工作区，输出掩码、中心线、交界仍恢复到完整640×480坐标；原图、相机内参、手眼/TCP和14mm算法不变。种子排除和负点实验均未启用。

离线对比在 `output/fixed_view_roi_20261104/`。本图固定ROI得到2个几何候选、1个模型端子，但仍有14个歧义实例，人工确认检查被拒绝。已减少干扰，**尚未证明局部路径可执行**，没有删除或放宽歧义阻断。

2026-11-05补充：手眼预览现支持普通左键在线身补正点、右键背景补负点。对本图先点线身中段，等待掩码清晰后按V复核，再Shift确认交界；详见[手动纠正](MANUAL_WIRE_CORRECTION.md)。单点纠正使用完整冻结原图作为SAM2上下文，不自动继承上述窄ROI；输出仍是原图坐标，窗口蓝框按实际裁剪范围显示。手动结果不重新运行YOLO，青色端子标记可能消失；人工交界流程仍可用。
